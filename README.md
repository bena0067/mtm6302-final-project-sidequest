# Sidequest

## Project Overview

Sidequest is a daily challenge web app designed to help users break out of their routine with small, playful real-world quests. Each day, the app gives the user one quest to complete.

## Features

- One random quest per day
- Quest categories
- Mark quest as complete
- Optional notes
- Streak counter
- Completed quest counter
- Quest history
- Local Storage
- Photo preview
- Light/Dark mode
- Shareable quest card (png)
- Reset options
- Responsive design

## Technologies Used

- HTML
- CSS
- Vanilla JavaScript
- Local Storage
- Canvas API

## Development Process

I first created the HTML structure and game-style interface. Then I added the daily quest system, completion button, notes, streak tracking, and quest history. I used Local Storage to keep user progress after refreshing the page. After the required features were working, I added the optional features such as categories, photo preview, theme switching, and a shareable quest card.

## Challenges

The main challenge was building the app using Vanilla JavaScript without frameworks. I had difficulty with the daily quest logic, streak tracking, and saving data with Local Storage. I solved these by breaking the features into smaller parts and testing each one separately.

## Testing

The application was tested for quest generation, completion, notes, streaks, history, reset options, theme switching, photo preview, mobile responsiveness and the generation, saving and sharing of the quest card.
