# Sidequest Project Documentation

## Client Communication

I selected Mehdi's Sidequest project from the Student Project Exchange.

I contacted Mehdi by email on August 9, 2026 to confirm that my interpretation of the project matched his expectations and to ask for feedback on the working application.

## Project Requirements

The main required features were:

- One daily quest from a preset list
- Mark quest as complete
- Optional note
- Streak counter
- Quest history with date and note
- Local Storage

Nice-to-have features included:

- Quest categories
- Photo preview
- Shareable quest card
- Light/dark mode

## Initial Assumptions

Before receiving client feedback, I developed the application based on the published project description.

I assumed:

- A new quest should appear when the date changes
- The same quest should remain during the same day
- Missing a day should break the streak
- Photo attachments should only be previews and should not be stored

## Prototype

I created a low-fidelity desktop wireframe showing the main structure and features of the application.

The prototype is included in the `Prototype` folder.

## Development Decisions

I used Vanilla JavaScript, HTML, and CSS.

Local Storage was used to save:

- Daily quest information
- Quest history
- Streak information

I also added reset options and a completed quest counter as extra features.
